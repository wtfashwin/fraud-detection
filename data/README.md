# Local training data

Compatible fraud data uses `Time`, `V1` through `V28`, `Amount`, and binary `Class`. Supply your own authorized dataset with `DATA_CSV`; keep real transaction data out of Git.

`python scripts/generate_synthetic_data.py` writes `data/creditcard.csv` and its synthetic metadata sidecar. Both are ignored by Git. Random synthetic labels test software behavior and cannot establish fraud accuracy.

The older credit-approval sample is retained separately under `archive/data/` and is deliberately incompatible with training.

`python scripts/fetch_benchmark.py` downloads the fixed public OpenML 42175 v1 benchmark, verifies its checksum/schema/counts, and writes `data/benchmark/creditcard.csv` plus provenance. This directory is ignored by Git and Docker. Choose a fresh directory with `--directory` if either output already exists; the command preserves existing outputs, a bad cached source, and the older `.arff.part` file. Cached sources must be regular files, not symlinks. The downloader requires `O_NOFOLLOW` and `O_NONBLOCK` to examine the source path, including on a fresh download, and fails closed when either is unavailable.

The source and generated CSV are buffered in memory with limits of 256 MiB and 512 MiB respectively; parsing, the data frame, and copies need additional memory. The filesystem must honor exclusive creation with `O_CREAT|O_EXCL`. Metadata is written before the CSV. The files are visible while writing, and publication is not atomic as a pair. If a write or collision fails, the error names files that may remain; inspect them and use a fresh directory.

The `training.train`, `training.tune`, `training.evaluate`, `training.preprocess`, and `scripts/validate_auc.py` commands verify a declared `csv_sha256` against the bytes they read from a local file. The two latter entrypoints retain pandas' compression inference; the hash for a compressed CSV describes the compressed file bytes. For file URLs, `scripts/validate_auc.py` uses urllib to open the file and checks the sidecar beside the opened path, including accepted local host aliases, queries, and fragments. A file URL fails closed if its opened path cannot be identified. Other URLs and open streams remain supported but have no automatically associated local sidecar. Snapshotting a CSV requires memory in addition to parsing.

Missing sidecars and sidecars without the hash remain supported and do not provide this check. To read a present sidecar, these commands require `O_NONBLOCK` and a regular file; a symlink to a regular sidecar remains supported. Platforms without `O_NONBLOCK` can still read datasets with no sidecar. The original historical `notebooks/feature_engineering.ipynb` checks a declared hash using a separate file read, so it does not bind that hash to the exact parsed snapshot. The separate `notebooks/feature_engineering_verified.ipynb` is an unexecuted copy for future runs that computes the hash of the bytes it parses and checks a declared sidecar hash when present. The downloader parses verified source bytes in memory; another process can replace source, CSV, or metadata paths during or after processing. No lock prevents another process from modifying a newly created file while it is being written. External readers are also outside the guarantee. See `docs/benchmark-results.md` for the executed holdout results and their limits.
